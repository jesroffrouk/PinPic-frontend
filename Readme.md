# PinPic

> *Share memories where they belong — in the places that made them special.*

---

## Overview

**PinPic** is a social platform where users can **bind images to specific locations** on the map.
Whenever someone visits that place, they can **discover memories**, photos, and moments shared by others — making every spot more meaningful and personal.

💬 Think of it as *Instagram meets Google Maps*, where every pin tells a story.

---

## About This Repo

This repository holds only the **frontend** of PinPic. It's built to be lightweight and self-contained on its own, but it doesn't do much alone all the real functionality, from authentication to image and location data, is served by the **PinPic backend**. The two are designed to work together as a single product: this frontend expects the backend to be running and reachable to function properly, and any changes to data models, auth flow, or APIs are driven from that side. For backend setup, API details, and how the two connect, check out the [https://github.com/jesroffrouk/PinPic-backend].
